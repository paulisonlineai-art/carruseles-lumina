# F08 · Carpeta + Post-it

Estilo instructivo lindo con elementos gráficos dibujados.

## Especificación
- **Fondo:** Blanco
- **Portada:** 
  - Foto real de escritorio, libreta de noche, o setup ritual
  - Texto arriba: "estos 5 hábitos me cambiaron la semana" (Inter 48 px, blanco con sombra)
- **Slides 2–N:**
  - Número pixel-art arriba a la izquierda: `1.`, `2.` (Press Start 2P o VT323, 32 px)
  - Ícono carpeta azul dibujado con código (SVG convertido a PNG), debajo el nombre: `ritual-de-la-mañana`, `pedir-señal`, `diario-de-gratitud` (Inter 28 px, azul `#4A90E2`)
  - Post-it amarillo `#FFF3A3`, levemente rotado (−2°), con 3–4 líneas de paso (Inter 26 px, negro)
  - Fondo gris claro `#F5F5F5`
- **Última slide:** "Lumina Manifestación" + post-it lila

## Mecánica
Muestra funciones de Lumina (ritual, señal, gratitud) sin mencionar el celular ni decir "descárgala".

## Ejemplos de temas
- Pasos de un ritual
- Pasos de gratitud diaria
- Pasos para pedir una señal
